# 本次会话补充：群聊首次响应时的主页频道提示

## 问题

群聊首次触发机器人时，如果网关仅按“没有历史消息 + Telegram 平台”判断，就会发送“未设置主页频道”的提示，打断正常的 @提及或回复对话。

## 稳定规则

- 主页频道只用于定时任务和跨平台投递，不是群聊对话的前置条件。
- 群聊、超级群组和论坛话题不应收到主页频道缺失提示。
- 该提示应仅保留给私聊等需要默认投递目标的场景。
- 修复网关首次消息处理逻辑时，除了检查平台和历史记录，还要排除 `chat_type` 为 `group`、`forum` 或 `channel` 的来源。
- 修改后执行 Python 语法检查；代码修复需要从网关外部重启，不能在网关自身进程内执行重启命令。
