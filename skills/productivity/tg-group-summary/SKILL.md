# Telegram 群聊折叠总结｜深度档案与原生 Details 折叠规范

## 一、核心原则与格式标准

1. **容器标准**：必须且只能使用 Telegram 原生 Rich Message `<details><summary>` 独立折叠块，严禁 `<blockquote>`、`**>`、`||`。
2. **内容密度**：**内容信息量要充足、适当加多展开细节**。拒绝一两句话泛泛而谈的概括，每要点展开至 100~200 字，详细记录具体的技术方案、配置参数、价格、报错原因、解决思路、各方争议与实际影响。
3. **独立档案**：每个独立事件使用一个独立的 `<details>` 折叠块；最后以独立的 `<details><summary>📋 总体结论与行动</summary>...</details>` 收尾。

## 三、排版与规范细节

- **列表符号**：统一使用空心圆 `◦ `（`U+25E6` + 半角空格）。
- **主体加粗**：人物/状态加粗，如 `<b>jobr wu:</b> `、`<b>如昔：</b> `、`<b>当前：</b> `。
- **人物称呼**：对齐长期花名册（如昔/爸爸、红猫、五哥、J佬、挽歌、L、浮生等），严禁空泛写“群友认为”。
- **来源链接**：私密群去除 `-100` 拼装 `https://t.me/c/{clean_id}/{msg_id}`，统一呈现为可点击的 `[来源]`。
