# Shlii NAT LXC 容器与轻量反代节点排查实战

## 1. Shlii 平台网络与端口映射机制
Shlii (或基于 Incus/LXD 的 NAT VPS 提供商) 采用 `IPv4 NAT & IPv6 NAT` 双栈架构：
- **容器内部端口**：控制台显示的 `SSH 端口: 22` 仅为容器内部监听端口。
- **外部连接端口**：外部 SSH 必须使用 NAT 端口映射表中的指定高位公网端口（如 `58085`），直接连接 `45.207.153.154:22` 将命中母机宿主机导致 `Permission denied`。
- **自定义端口添加**：平台支持自主添加 TCP 端口映射（如内部 `18096` -> 外部 `29759`），用于视频流反代或 Web 服务。
- **连接命令规范**：
  ```bash
  sshpass -p '<PASS>' ssh -o StrictHostKeyChecking=no -p <EXTERNAL_NAT_PORT> root@<SERVER_IP>
  ```

## 2. 台湾 (TW) vs 香港 (HK) vs 荷兰 (NL) 节点特性与 Emby 4K 播放场景选型

| 节点 | 物理延迟 (Ping) | 出口带宽限制 | 适用场景 |
|---|---|---|---|
| **🇹🇼 台湾 (PEER739-HKTW2)** | ~34ms (极低) | ~215 Mbps (26.9 MB/s) | **4K 原盘 / 高码率 Emby 秒开首选** (延迟与带宽双优) |
| **🇭🇰 香港 (156.245.245.172)** | ~20ms (极低) | ~20 Mbps (2.3 MB/s 封顶) | **1080P / 常规剧集秒开** (高码率 4K 会因带宽跑满缓冲) |
| **🇳🇱 荷兰 (199.47.241.137)** | ~300ms (高延迟) | ~924 Mbps (千兆大水管) | **欧洲/美区源站分流 & 离线缓存下载** (起播需缓冲2~3秒) |

## 3. LXC 超轻量节点部署约束 (128MB RAM / 512MB Disk)
- 严禁部署重量级面板 (NPM / 1Panel / Baota / Docker)。
- 推荐使用 Python3 原生 `http.server` + Nginx 极简 Agent (整套服务仅占 ~15MB RAM)。

## 4. 前端渲染与节点 IP 回显陷阱 (NODE_IPS 字典同步)
在多节点管理面板前端渲染卡片时：
- 若前端硬编码的 `NODE_IPS` 字典（如 `{ hk: '...', nl: '...' }`）未同步新增的节点代号（如 `tw`），会导致渲染 fallback 回退到默认主节点 IP（如荷兰 IP），表现为“后端数据已通，但网页上复制地址仍显示旧 IP”。
- **修复规范**：每次在集群主控端扩展节点时，必须确保前端 JS 字典、后端 API 以及 Nginx 配置三端同步更新映射关系。
